# NBA Player Salary Efficiency Model

A data science project measuring every NBA player's production relative 
to their contract value across 15 seasons — designed as a front office 
decision support tool and standalone analytics portfolio piece.

**Scope:** 2010–present · 500+ player-seasons · Multi-source pipeline
(nba_api + Basketball Reference) · Unsupervised clustering → surplus archetypes

**Core question:** Which players deliver the most value relative to what 
they're paid — and which organizations consistently find that surplus?
